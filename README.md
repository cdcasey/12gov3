# One to Grow On

One to Grow On is a podcast where we dig into questions about agriculture and try to understand how food production impacts us and our world. Each episode, hosts Hallie and Chris pick an area of agriculture or food production to discuss. Listen for plant facts, dad jokes, and the stories behind your food.

One to Grow On is an older kid-friendly podcast that is safe and appropriate for listeners of all ages. There are a few clearly marked episodes that contain content that may not be suitable for all ages.

- **Site:** https://www.onetogrowonpod.com
- **Feed:** https://www.onetogrowonpod.com/feed/podcast (redirects to `/feed/podcast/index.xml`)

## Development

Astro static site. Requires Node 22.12 or later and pnpm.

| Command        | Action                                |
| -------------- | ------------------------------------- |
| `pnpm install` | Install dependencies                  |
| `pnpm dev`     | Dev server at `http://localhost:4321` |
| `pnpm build`   | Production build to `./dist/`         |
| `pnpm preview` | Serve the production build locally    |

- **Content:** one directory per post in `posts/`. The frontmatter `slug` sets the URL.
- **Audio:** hosted in a Cloudflare R2 bucket and referenced by URL in each post's frontmatter.
- **Feed:** generated by `src/pages/feed/podcast/index.xml.ts`. Never change a post's `guid`.

## Deployment

Cloudflare Pages builds and deploys on every push. `main` goes to production at
https://12gov3.pages.dev. Other branches get a preview at `<branch>.12gov3.pages.dev`.
Redirects live in `public/_redirects`.

## Remaining launch tasks

- [x] Move the DNS zone to Cloudflare and attach `www.onetogrowonpod.com` and the bare domain to the Pages project. Add a redirect from the bare domain to `www`.
- [x] Validate the live feed with https://www.castfeedvalidator.com and https://podba.se/validate/.
- [ ] Set the feed URL in Apple Podcasts Connect and Spotify to `https://www.onetogrowonpod.com/feed/podcast/index.xml`.
- [ ] Retire the Netlify site and the old WordPress host once the directories have picked up the new feed URL.
- [ ] Optional: add `cdn.onetogrowonpod.com` as a custom domain on the R2 bucket and switch the audio URLs. Keep the `r2.dev` URL enabled afterward.

Migration history and the final WordPress feed snapshot are in `archive/`.
